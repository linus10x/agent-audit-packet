## 1. Goal
A field reviewer clones ONE repo, runs ONE command (`./verify.sh`), and gets reviewer-readable evidence that an under-governed payments agent FAILS a regulated OFAC control (ALLOWs the screen-completes-after-transfer race) and a governed agent PASSES it (DENYs the race), with a CI-grade exit code. Go-to-market wrapper around the already-proven `agent-funds-gate` control; not a new control and not a generic agent framework.

## Injection posture (external-content rule)

### audit_packet.verify  (module entrypoint: `python3 -m audit_packet.verify`)
```
def main(argv: list[str] | None = None) -> int
    # The CI-grade audit driver. Steps, in order:
    #   1. run_all_probes()
    #   2. build_evidence(results) -> EvidenceReport
    #   3. print render_table(report) to stdout (defeat-first narrative line, then the table)
    #   4. if "--json" in argv (or always): also write render_json to ./evidence.json (path is in-tree, no network)
    #   5. run the packet's own probe test suite in-process (pytest.main(["-q", tests_dir])) as a regression guard
    #   6. return 0 IFF report.all_pass is True AND the test suite returned 0; else return a NON-ZERO code.
    # Distinct error codes (documented in 5): 0 ok; 2 a probe regressed (governed ALLOWed); 3 a test failed;
    # 4 vendored-gate integrity failure; 5 internal error / empty run. Any unexpected exception -> non-zero.

if __name__ == "__main__":  # guarded entry
    raise SystemExit(main())
```
`main` never raises out to the shell on a handled failure — it returns the matching non-zero code so the exit contract is deterministic. An UNHANDLED exception still results in a non-zero exit (fail-closed); it must never exit 0.

## 5. Failure modes (must fail CLOSED)
- **Governed path ever ALLOWs the race** (control removed/regressed): `outcome` is FAIL, table/JSON print FAIL, `all_pass` is False, `main` returns 2. Tests 3.7, 3.13.
- **Evidence asserts PASS while a probe ALLOWed**: impossible by construction — PASS is derived from the real `GateDecision.decision`; no literal "PASS" path exists. Test 3.7.
- **Driver exits 0 despite a regression** (probe FAIL or test failure): forbidden; `main` returns non-zero (2 or 3). Tests 3.13, 3.14.
- **Empty / no probes run**: `build_evidence([])` raises; `main` returns 5; never renders green. Test 3.9.
- **Vendored gate drifts from its pinned SHA**: content digests recomputed each run; mismatch fails the integrity test and (when run via the driver's step 5) returns 4. Test 3.19.
- **Crash mid-run / unhandled exception**: `main` returns non-zero; `verify.sh` (`set -e`, `exec`) propagates non-zero. The shell never sees 0 on a crash.
- **Missing file / corrupt vendored module / missing python3**: import or integrity step fails -> non-zero exit; never silently passes.
- **Malformed input reaching the gate**: handled by the vendored control itself (it DENYs `transfer_seq_invalid`/`screen_malformed`, never raises). The packet does not feed external input; v1 fixtures are well-formed by construction.
- **Mac asleep / interrupted**: the packet is a synchronous one-shot CLI with no scheduler, no daemon, no state. An interrupted run leaves no partial green signal (exit code only emitted on completion; a killed process yields a shell non-zero/None, never 0-as-success).

## 6. One-command repro design (entrypoint + output + exit contract)
- Entrypoint (human): `./verify.sh` from the repo root of a fresh clone. Equivalent: `python3 -m audit_packet.verify`.
- What it prints (in order): (1) one defeat-first narrative line — the under-governed agent ALLOWs a $250,000 transfer whose OFAC screen completes at seq 15, after the money moved; (2) one line showing the governed gate DENYs the same race with the OFAC cite and the named assertion (both read from the decision); (3) the second-line evidence table (PROBE | CONTROL | REG ANCHOR | ASSERTION | RESULT); (4) a final verdict line (ALL PASS / REGRESSION); (5) writes `./evidence.json` for forwarding.
- Exit-code contract: `0` = every probe PASS and embedded tests green (control holds); `2` = a probe regressed (governed ALLOWed); `3` = an embedded test failed; `4` = vendored-gate integrity mismatch; `5` = empty run / internal error; any other non-zero = unhandled failure. A reviewer can wire `./verify.sh` straight into CI and treat non-zero as "the control does not hold here."
- Framing law in all output prose: "we attacked our own gate," never "caught a real incident." Defeat shown first, control second. Plain ASCII, no em-dash connectors, none of the banned brand terms.

## 7. WHAT THE PACKET ADDS vs WHAT IT REUSES from agent-funds-gate
REUSES (verbatim, vendored, unchanged — the proven control and its proof):
- The `FundsGate` ordering enforcement and `naive_mode` defeat.
- `ScreenResult`, `ScreenStatus`, `GateDecision`, the `OFAC_CITE` string, and the `screen_completion_precedes_execution` assertion.
- The polarity-proven invariant and its independent-review record (referenced, not re-litigated).
The packet writes ZERO gate logic (test 3.22 enforces this) and imports the real public surface (test 3.21).

ADDS (the moat — real, not a rename):
- A CI-grade DRIVER (`verify.py` + `verify.sh`) with a deterministic multi-code exit contract and an embedded regression suite. Upstream `demo.py` is a narrative print with no exit code and no test run; this is a gate a reviewer can put in CI.
- A second-line EVIDENCE layer (`evidence.py`): a reviewer-readable table + a forwardable machine-readable `evidence.json`, every cell derived from the actual gate decisions, structured as the model-risk / independent-review function would record it (control, reg anchor, assertion, PASS/FAIL).
- A probe REGISTRY (`probes.py` + `PROBE_REGISTRY` + `CONTROL_INDEX.md`) built for extension (ECOA, SR 11-7 are named roadmap rows), shipping exactly one proven probe in v1.
- A single-clone, zero-install, no-network packaging discipline: vendored gate with pinned per-file digests and a `VENDOR.md` provenance record, so the whole thing is one `git clone` then one command.
The split: agent-funds-gate PROVES the control; agent-audit-packet makes that proof forwardable, runnable in one command by a non-author reviewer, and emits independent-review-grade evidence with a CI exit code.
